# Retours : ce qui attend encore l'utilisateur
Ce dossier contient seulement ce qui attend une reponse : un essai a jouer ou une question sans reponse.
Convention des noms : E-<scenario>.md = essai a jouer (commande play.ps1, reponse OK / BUG / REGLAGE) ; Q-<sujet>.md = question a options A/B/C ; BUG-<sujet>.md = bug ouvert avec ses mesures ; F-<sujet>.md = faits et mesures (pas une question).
Autres fichiers : ESSAIS-A-JOUER.md (liste des essais a donner, a rejouer sur le main du jour avant de la donner) et REPONSES-2026-11-09.md (decisions de l'utilisateur a executer, garde tant que D753-D766 ne sont pas au GDD).
Une fiche repondue et reportee dans son chantier (*InProgress.md, EtapeDefini.md) est archivee dans Docs\Archive\Retours_<date>\ (rien n'est supprime) ; premiere archive : Docs\Archive\Retours_2026-11-10\.
Le suivi des essais et des questions de la journee est dans Auto_Journey_Retours.md ; la file de travail est dans Auto_Journey_File.md.
