### Comment éviter la double source

Presque toutes ces règles ont des appelants C++ qui ne migrent qu'aux étapes 4 et 5 (écrans, contrôleur, `GameMode`). Réécrire la
règle en script maintenant créerait la double source que l'étape 0 interdit. Trois façons propres, une par lot :

- **P (contrôle de données)** : le test C++ vérifie un fichier, pas une règle. Il devient un contrôle python dans
