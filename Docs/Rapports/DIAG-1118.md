## Échec 1 : le 404 (partie normale, 2 places Petite)

- Émis par : le script PowerShell lui-même (pas le client du jeu, pas le serveur dédié). `catch { $Failure = "$_" }`
  (`lobby_match.ps1:735`) imprime le message brut de `Invoke-RestMethod`.
- Requête : `GET http://127.0.0.1:<port>/lobbies/L1`, `lobby_match.ps1:577`
  (`while ((Invoke-RestMethod "${Url}/lobbies/$($Lobby.id)" -TimeoutSec 2).state -ne "in_game")`), qui suit directement
  l'affichage `lobby L1 created by Alice, Plain Small, 2 places` (ligne 567). C'est la seule requête REST du chemin normal
  juste après cette ligne, et elle est lancée avant « lobby L1 in_game: Carol started » (jamais imprimé).
- Route : elle existe et script et gestionnaire sont d'accord. `Manager\HOLManager\Api\LobbyRoutes.cs:83`
  `MapGet("/lobbies/{lobbyId}")` ; `LobbyErrors.LobbyNotFound` mappé en 404 (`LobbyRoutes.cs:30`). Le manager.log du passage
  -Faction (`Saved_Tests\LobbyMatch\manager.log`) montre 240 GET `/lobbies/L1` en 200, 1 POST `/lobbies` 201, 1 POST `/join` 200,
  1 PUT `/settings` 200, 2 POST `/leave` 204, aucun 4xx/5xx : routes, port, identifiants et serveur stagé sans problème.
  Il n'y a pas de « serveur stagé périmé » dans ces journaux : le gestionnaire n'a même pas eu à lancer de serveur de
  match, le lobby n'a jamais été lancé.
- Mécanisme (inféré, voir limites) : le pas `$ToSmall` (script ligne 146) attend `... catastrophe 0 accepted`, même motif
  périmé, donc Alice atteint le timeout du pas, quitte le salon, puis Bob (qui attendait `2/2 ready`) fait de même. Le dernier
  joueur parti supprime le salon (`/leave` 204 puis lobby inconnu), et la boucle de la ligne 577 fait alors un GET sur un
  salon disparu : 404 levé par `Invoke-RestMethod` avant le test `$Games.Bob.HasExited` de la ligne 578, d'où ce message
  trompeur au lieu de « the lobby never in_game ». Durée 110 s cohérente avec un timeout de pas, pas avec un match.
- Antérieur à ce soir : oui, même cause que ci-dessus (13 novembre). Le constat du matin du 18 (« serveur stagé périmé,
  404 du manager ») avait la bonne observation (404) mais la mauvaise explication.
