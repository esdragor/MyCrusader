# Brouillard (F7.3) : les lignes d'ordre restent visibles sous le noir (deux deplacements en file vers l'inexplore)
# Plain, moi (slot 0) et un adversaire (slot 1). Positions dans le repere du centre du joueur (cm).
hol.Fog.Mode 2
hol.Fog.Render 1
open /Game/Maps/Plain
waitmap Plain
waitlog Camera above the start of slot
frames 5
hol.Camera.FocusNear 800 0
frames 2
hol.Units.SpawnHere 4 ManAtArms 0 250
waitunits 4
hol.Camera.FocusNear 10000 0
frames 2
hol.Units.SpawnHere 5 Spearman 1 350
waitunits 9
hol.Camera.FocusNear 4500 0
hol.Camera.Zoom -1
frames 30
hol.Select.Own
waitlog Selection: 4 units (own)
hol.Select.OrderNear 6500 0
frames 5
hol.Select.OrderGround -9000 3000 shift
frames 5
# Les hommes marchent : le brouillard doit rester dessine (mode 1) apres les ordres, pendant la marche et a la fin (retour de l'utilisateur 2026-10-30 : le scenario le coupait lui-meme).
wait 3
hol.Fog.RenderReport
waitlog Fog render: mode 1
hol.HUD.Report 1
capture fogord_a
wait 3
hol.Fog.RenderReport
waitlog Fog render: mode 1
capture fogord_b
note Deux deplacements en file (jaune) vers le noir : leurs lignes et leurs points se voient jusqu'au bout. Maj + clic droit pour en ajouter ; le serveur refuse d'attaquer un ennemi hors de vue.
note Le brouillard reste en place pendant et apres la marche (le scenario ne le coupe plus). hol.Fog.Render 0 / 1 dans la console pour le comparer.
note Epaisseur (option B, par defaut) : 12,5 cm sous brouillard actif, 6,25 cm sans brouillard. Console : hol.Orders.LineWidthFog 6.25 (A, comme avant) / 12.5 (B) / 25 ; hol.Orders.LineWidth 12.5 (C : plus epais aussi sans brouillard).
note Halo anti-gresillement (essai) : hol.Fog.OrderMask 1.5 etale le masque du pochoir d'un pixel autour des lignes ; 0 = comme avant. Dis lequel grésille le moins.
