# Technologies (T5, WorkerSpeed) : la Brouette accelere la marche des Paysans du proprietaire (+10 %, 800 -> 880 cm/s), pas les autres unites ni les autres joueurs
# Plain, toi (slot 0) contre une IA (slot 1), 5 Paysans. Ce scenario est aussi le test de la chaine : chaque waitlog doit arriver. hol.Units.Formation dit, par unite, sa vitesse mesuree (speed) et sa vitesse de marche (own).
# Recherche de 2 s (hol.Prod.BuildTime 2) ; hol.Hero.SetXP 0 600 = niveau 3 = palier 1.
waitlog Starting hero of slot 0 spawned at
hol.Cheat.Resources 5000
hol.Prod.BuildTime 2
hol.Camera.FocusNear 2500 2500
frames 2
hol.Cheat.SpawnBuilding Farm 0 2500 2500
waitlog Cheat: spawned Farm of slot 0
note 1. Sans la Brouette : un Paysan marche a 800 cm/s.
hol.Units.Formation 0
waitlog own 800 march
hol.Select.ClickUnit 0
frames 2
hol.Select.OrderGround -13000 0
wait 1.2
hol.Units.Formation 0
waitlog speed 800 own 800
wait 2
note 2. Brouette cherchee a la Ferme (palier 1).
hol.Hero.SetXP 0 600
waitlog Hero level up: slot 0 level 1 -> 3
frames 4
hol.Prod.Queue WheelbarrowI Farm
waitlog Technology: slot 0 researched WheelbarrowI
frames 4
note 3. Avec la Brouette I : la marche d'un Paysan est a 880 cm/s (+10 %), la vitesse mesuree suit sur une vraie marche.
hol.Units.Formation 0
waitlog own 880 march
hol.Camera.FocusSlot 0
frames 3

frames 2
hol.Select.OrderGround -14800 0
wait 0.8
hol.Units.Formation 0
waitlog speed 880 own 880
note 4. Le Paysan en marche va a 880 cm/s mesures (speed 880 own 880), 800 avant la Brouette.
