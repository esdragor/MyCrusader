# Plain, quatre joueurs (forum_messages.json) : moi (slot 0) et Joueur 3 (slot 2, IA alliée) dans l'équipe 1 ; Joueur 2

# l'allié : ligne + bandeau + son. Le panneau du scénario recouvre la place du bandeau d'alerte (même endroit, en haut au
# centre) : tout le déroulé est donné au départ, puis l'utilisateur ferme le panneau (×) ; la touche Entrée marche encore.

note Entrée 3 (éloigne d'abord ta caméra) : « Joueur 4 tient votre ruine » : clique le bandeau dans les 4 s : caméra sur ton forum.
note Entrée 4 (éloigne ta caméra) : le forum de Joueur 3 (allié) tombe : bandeau + son ; clique-le : caméra sur son forum.
note Entrée 5 : « Joueur 2 est vaincu » (fil seul). Entrée 6 : « Vous êtes vaincu » dans le fil, bandeau Défaite, pas d'alerte.
